# backup-shell-script
# Automated Backup Script 🗂️

This project is a shell script that automates directory backups.

## Features
- Automatic backup
- Timestamp naming
- Compression (.zip)
- Keeps last 7 backups (rotation)

## Tech Used
- Linux
- Shell Scripting
- zip
- cron (optional)

## How to Run
chmod +x backup.sh
./backup.sh
